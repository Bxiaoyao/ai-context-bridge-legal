Privacy Policy

AI Context Bridge (“the Extension”) is a browser extension that helps you widen AI chat layouts, copy clean Markdown, and hand off conversation context between ChatGPT, Claude, Gemini, and DeepSeek.

1. Data we do not collect

The Extension does not transmit your conversation content, prompts, responses, screenshots, or license status to any remote server operated by us. There is no analytics backend, no account system, and no cloud sync in the MVP.

2. Data stored locally

The following may be stored in your browser via chrome.storage.local:

  • Per-site width preferences
  • UI position of the floating capsule
  • Preference to filter Thinking / Reasoning blocks
  • Custom handoff templates you create
  • License key (if you activate Pro)
  • Daily usage counters for Free limits
  • Temporary handoff payload for cross-tab prefill (auto-cleared)

3. Permissions

  • storage — local preferences and license
  • clipboardWrite — copy clean Markdown / handoff prompts
  • activeTab / host permissions — only for ChatGPT, Claude, Gemini, and DeepSeek web apps

We never request all_urls.

4. Third parties

If you purchase a Pro license in the future, payment is handled by a Merchant of Record (e.g. Creem / Lemon Squeezy / Paddle). Their privacy policies apply to checkout. The Extension only receives a license key you paste locally.
