Privacy Policy

WideRelay (“the Extension”) is a browser extension that helps you widen AI chat layouts, copy clean Markdown, and hand off conversation context between ChatGPT, Claude, Gemini, and DeepSeek.

1. Data we do not collect

The Extension does not transmit your conversation content, prompts, responses, screenshots, to any remote server operated by us. There is no analytics backend, no account system, and no cloud sync.

2. Data stored locally

The following may be stored in your browser via chrome.storage.local:

  • Per-site width preferences
  • UI position of the floating capsule
  • Preference to filter Thinking / Reasoning blocks
  • Custom handoff templates you create
  • Interface language preference
  • Temporary handoff payload for cross-tab prefill (auto-cleared)

3. Permissions

  • storage — local preferences and templates
  • clipboardWrite — copy clean Markdown / handoff prompts
  • activeTab / host permissions — only for ChatGPT, Claude, Gemini, and DeepSeek web apps

We never request all_urls.

4. Third parties

WideRelay is free and unlocks nothing behind a payment. The popup and settings page contain an optional link to ko-fi.com/widerelay for voluntary support. The link only opens in a new tab when you click it; the Extension sends no data to Ko-fi, and Ko-fi’s own privacy policy applies once you are on their site.
